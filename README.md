# Jujutsu Fight v34

A lightweight Canvas 2D browser fighting game project.

## Open locally
Open `index.html` in a modern browser. The main menu contains the current game modes and control guide.

## Included in this version
- Per-character idle and run animation pass
- Heian Sukuna Hiten skill 7 and World-Cutting Slash pose pass
- Gojo Awakening and Hollow Purple overhaul
- Young Gojo Maximum Output: Blue restoration
- Non-sticky traversal and safe platform top-out fixes

## Publish a browser preview with GitHub Pages
This repository is structured for a root-level static site. In GitHub, open **Settings → Pages**, choose **Deploy from a branch**, select branch **main** and folder **/(root)**, then Save.

After GitHub Pages finishes publishing, the expected URL is:
https://toikhong713-hue.github.io/jujutsu-fight-preview/

The repository is public, so the game source code is public too.
